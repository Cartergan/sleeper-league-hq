# League HQ

A production-ready static fantasy football league headquarters powered by the public Sleeper API.

League ID: `1339982718628274176`

## Features
- Live standings, records, PF/PA and win percentage
- Current-week matchup cards
- Power rankings
- Weekly awards / scoring leaders
- Last-place watch
- Team and roster browser with search
- Transaction / trade center
- Sleeper playoff bracket
- Dark mode
- Responsive mobile layout
- Share-link button
- Automatic refresh every 5 minutes

## GitHub Pages
Upload these five files to the repository root and publish `main` / `(root)` from Settings → Pages.
